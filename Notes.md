### Stream 
Stream ka matlab hota hai data ya information ka lagataar flow, yani cheezon ka continuously ek jagah se doosri jagah move hona.

Simple words mein:
👉 Stream = musalsal behne wali cheez ya continuous flow 

Examples:
  1- Video streaming → video continuously internet se load hoti rehti hai.
  2- Data stream → data step by step system mein aata rehta hai.


### Socket
Socket ek communication endpoint/darwaza hota hai jo do computers ya devices ko network ke through aapas mein connect karke data send aur receive karne deta hai.

Simple words mein:
👉 Socket = network par do systems ke darmiyan baat karne ka connection point

Example:
 1- Jab browser server se website data leta hai, to socket connection use hota hai.
 2- Chat apps (WhatsApp jaisi) real-time messages bhejne ke liye sockets use karti hain.


### Duplex Stream
Duplex Stream ek aisi stream hoti hai jisme data ek hi waqt mein send bhi kiya ja sakta hai aur receive bhi kiya ja sakta hai.

Simple words mein:
👉 Duplex Stream = do-tarfa data flow (send + receive at the same time)

Example:
  1- Phone call mein dono log ek sath baat bhi kar sakte hain aur sun bhi sakte hain — ye duplex communication hai.
  2- Chat applications ya sockets duplex streams use kafrti hain.

### Chunk
Chunk ka matlab hota hai kisi bari cheez ka chhota hissa ya tukra.

Simple words mein:
👉 Chunk = data ya information ka small piece jo bade data ka part hota hai

Examples:
  1- Internet par file download hoti hai to wo chhote chhote chunks mein aati hai.
  2- Video streaming mein data ek sath nahi balkay chunks mein load hota hai.


### Buffer
Buffer ek temporary memory space hoti hai jahan data ko kuch dair ke liye store kiya jata hai taake data smoothly send ya receive ho sake.

Simple words mein:
👉 Buffer = temporary jagah jahan data temporarily rakha jata hai processing se pehle ya baad mein

Examples:
  1- Video play hone se pehle thoda data buffer mein load hota hai (buffering).
  2- Programming mein data pehle buffer mein aata hai phir process hota hai.
